# Troubleshooting

Documentation of technical problems encountered during the learning journey and how they were investigated and resolved.

##  Problem-Solving Approach

Where appropriate, each case should document:

1. Problem
2. Expected behaviour
3. Actual behaviour
4. Investigation
5. Root cause
6. Solution
7. Lessons learned

##  Professional Value

Troubleshooting evidence demonstrates the ability to investigate problems rather than simply follow predefined instructions.
