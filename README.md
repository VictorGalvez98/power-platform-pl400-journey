My journey towards becoming a Power Platform Developer.

This repository documents my learning process while preparing for the Microsoft PL-400 certification, with a focus on developing practical skills that can be applied in real-world Power Platform projects.

- Learning Power Platform development concepts

- Investigating technical problems
- Documenting solutions and technical decisions
- Developing good development and ALM practices
- Building evidence of my technical progression
